# 环境变量与配置说明

本文汇总 **`gustobot/config/settings.py`**（`pydantic-settings`）从环境变量与 **`.env`** 读取的配置项，按模块分组说明用途与默认值。**若与代码不一致，以 `settings.py` 为准**。

加载方式：`Settings` 默认读取项目根目录 `.env`（`model_config.env_file`）；Docker Compose 等也可直接注入同名环境变量。

---

## 1. 应用与 HTTP

| 变量 | 默认 | 说明 |
|------|------|------|
| `APP_NAME` | `GustoBot` | 应用名 |
| `APP_VERSION` | `0.1.2` | 版本 |
| `DEBUG` | `True` | 调试开关 |
| `API_V1_PREFIX` | `/api/v1` | REST v1 前缀 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `8000` | 监听端口 |

---

## 2. LLM（主对话 / 路由 / Agent）

| 变量 | 说明 |
|------|------|
| `LLM_PROVIDER` | 提供商标识，默认 `openai` |
| `LLM_MODEL` | 模型名，默认 `gpt-4-turbo-preview`；别名 **`OPENAI_MODEL`** |
| `LLM_API_KEY` | API Key；别名 **`OPENAI_API_KEY`** |
| `LLM_BASE_URL` | API Base；别名 **`OPENAI_API_BASE`** |

代码中通过属性 **`OPENAI_API_KEY` / `OPENAI_API_BASE` / `OPENAI_MODEL`** 与旧逻辑兼容，实际映射到上述 `LLM_*`。

**Anthropic（可选）**：`ANTHROPIC_API_KEY`、`ANTHROPIC_MODEL`。

---

| `IMAGE_GENERATION_API_KEY`、`IMAGE_GENERATION_BASE_URL` | 文生图服务 |
| `IMAGE_GENERATION_MODEL` | 如智谱 CogView 等 |
| `IMAGE_GENERATION_SIZE` | 默认 `1024x1024` |

## 4. Embedding

| 变量 | 默认 | 说明 |
|------|------|------|
| `EMBEDDING_PROVIDER` | `openai` | 提供商 |
| `EMBEDDING_MODEL` | `text-embedding-3-small` | 模型名 |
| `EMBEDDING_API_KEY` | — | 缺省时不少路径会回退到 `LLM_API_KEY` |

## 5. Reranker（主应用知识检索）

| 变量 | 默认 | 说明 |
|------|------|------|
| `RERANK_ENABLED` | `True` | 是否启用精排 |
| `RERANK_PROVIDER` | `custom` | 如 cohere / jina / voyage / custom |
| `RERANK_BASE_URL` | — | 服务根 URL |
| `RERANK_ENDPOINT` | `/rerank` | 路径 |
| `RERANK_MODEL` | `bge-reranker-large` | 模型名 |
| `RERANK_API_KEY` | — | 鉴权 |
| `RERANK_MAX_CANDIDATES` | `20` | 参与精排的候选条数 |
| `RERANK_TOP_N` | `6` | 精排后保留条数 |
| `RERANK_TIMEOUT` | `30` | 秒 |
| `RERANK_SCORE_FUSION_ALPHA` | — | 分数融合（可选） |

**旧名兼容**：`RERANKER_PROVIDER`、`RERANKER_API_KEY`、`RERANKER_MODEL`、`RERANKER_API_URL`、`RERANKER_TOP_K` 通过 **property** 映射到上述字段（见 `settings.py`）。

## 15. CORS

| 变量 | 默认 |
|------|------|
| `CORS_ORIGINS` | `http://localhost:3000,http://localhost:5173`（逗号分隔字符串） |

代码通过 **`cors_origins_list`** 将逗号分隔字符串解析为列表。当前 **`gustobot/main.py`** 中 `CORSMiddleware` 使用 **`allow_origins=["*"]`**（开发/测试便利），**未读取** `CORS_ORIGINS`；若要在生产收紧来源，需改 `main.py` 或中间件逻辑。

## 18. `.env` 示例（按需裁剪）

```bash
# --- 主 LLM（必填，按你的网关填写）---
LLM_API_KEY=sk-...
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini

# --- Embedding ---
EMBEDDING_API_KEY=sk-...
EMBEDDING_BASE_URL=https://api.openai.com/v1
EMBEDDING_MODEL=text-embedding-3-small
EMBEDDING_DIMENSION=1536

# --- Rerank（可选）---
RERANK_ENABLED=true
RERANK_BASE_URL=https://your-rerank-host/v1
RERANK_API_KEY=...

# --- 数据与缓存 ---
DATABASE_URL=mysql+pymysql://user:pass@localhost:13306/recipe_db
REDIS_URL=redis://localhost:6379/0
MILVUS_HOST=localhost
MILVUS_PORT=19530
NEO4J_URI=bolt://localhost:17687
NEO4J_USER=neo4j
NEO4J_PASSWORD=...

# --- LightRAG ---
LIGHTRAG_WORKING_DIR=./data/lightrag
INIT_LIGHTRAG_ON_BUILD=true

# --- 前端 CORS ---
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

勿将真实密钥提交到 Git；生产建议使用密钥管理或编排平台注入环境变量。

## 20. 常见问题

**Q：只配 `OPENAI_API_KEY` 可以吗？**  
可以，`LLM_API_KEY` 与 `OPENAI_API_KEY` 为别名关系（见上表）。

**Q：Embedding 与 LLM 能否用不同厂商？**  
可以，分别设置 `EMBEDDING_*` 与 `LLM_*`；注意 `EMBEDDING_DIMENSION` 与向量索引一致。

**Q：如何关闭 Rerank？**  
设置 `RERANK_ENABLED=false`。

**Q：Compose 里变量从哪来？**  
根目录 `.env` 与 `docker-compose.yml` 中的 `environment` 会覆盖本地默认值；以实际 Compose 文件为准。
